## 接入方式

目标镜像的 zram 已回移 Crypto API 后端，不能仅用主版本判断它仍是早期私有压缩器接口。实际 `zcomp_available_algorithm`、`zcomp_compress` 和原生 Crypto API 入口支持本轮注册路线，目标符号表未找到 ZSTD 实现。

模块在 `post-kernel-init` 注册，启动配置须在 zram 初始化前选择 `zstd`。`pre-kernel-init` 在调用 Crypto API 前返回错误。原生算法可用时返回 `-EEXIST`，保留原生实现。

压缩器初始化时分配各自的工作区，压缩回调复用工作区。注册前进行一次页面编解码比对。算法对象采用清零静态存储，只填写使用的字段，`cra_module` 留空。

注册表和压缩器回调会长期引用 KPM 内存，因此注册成功后须保持模块常驻。退出入口只能提醒；KP 手动卸载不能依赖退出返回值阻止。README、模块描述和日志均提示不可卸载。手动加载只能验证注册，已有 zram 不会因此切换算法。
