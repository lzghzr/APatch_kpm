# Developer 报告目录

每轮实现产出一份开发报告，用 `docs/templates/developer-report.md`，命名 `<日期>-<模块>-<版本>.md`。

必须包含：

1. 身份三要素（commit + Build ID + 每个产物 SHA-256）；
2. 变更点与意图（改了哪些 hook 点/偏移/数据结构，刻意不做什么）；
3. 自检命令与输出（构建、离线语料回归、代码走查）；
4. **边界声明**：这是实现方自检，不是独立审计，也不是实机结论；
5. 未解决项与降级行为（哪些内核缺少哪些符号、降级成什么）；
6. 主动列出的「已知可疑点」，供 Auditor 重点检查。

规则：报告只追加，不覆盖旧结论；发现问题开 `DEV-xxx` 单并在报告里登记状态。
