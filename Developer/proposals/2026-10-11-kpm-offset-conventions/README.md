# KPM 偏移开发约定

按用户本轮要求更新两份技能，工作树已落地。维护者可逐字节核对 [skills.patch](skills.patch) 并提交技能路径。

开始写代码前加载开发及相关专门技能；先复用 `*_structs.h` 中已核对的定义，仅为无法覆盖的字段获取偏移。BTF 查询放 `*_btf.c`，固定窗口函数推导、配置与调度放 `*_offsets.c`。指令识别和解码统一使用 `kpm_utils.h`；先比较短函数入口，再选择内联调用者或较长函数段。

两份技能已读回核对；zram_zstd 本轮按这些约定整理，实际偏移与产物自检见 [开发报告](../../reports/2026-10-11-zram-zstd-kernel-compat.md)。
