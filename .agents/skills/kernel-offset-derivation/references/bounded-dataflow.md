# 有界数据流与探测读取

用于短入口匹配不足，需要从字段的已知使用点回溯，或处理跳板、多候选与不确定地址读取时。直接匹配已能充分确认语义的锚点继续使用原规则；这些方法不要求建立通用反汇编或控制流框架。BTF 与失败契约沿用 [偏移获取主技能](../SKILL.md)。

## 从使用点回溯到真实对象

先确认使用点的含义和 ABI，例如某次原生锁调用确实接收目标对象中的锁地址，再在固定小窗口内反向追踪该参数的定义。识别所需的 MOV、ADD、MOVZ/MOVK 等实际形态，最终建立“已知对象基址 → 字段地址 → 已确认用途”的完整链。

- 把下界和上界传给回溯逻辑，限制每次取指、前瞻和分支目标；反向搜索不能越过已确认的函数入口或所选窗口起点。窗口里证据不足就失败。
- 基址来源必须来自已确认的参数、对象读取或保存关系。x19 等被调用者保存寄存器只说明调用约定，不证明它保存的是 `mm_struct`；偏移的对齐和数值范围仅作必要检查。
- 按实际编码处理写寄存器集合：LDP 的两个目的寄存器、加载／存储写回的基址、STXR 状态寄存器、CAS 比较寄存器。不能统一把低 5 位当成唯一目的寄存器。
- 区分 W/X 数据宽度及零扩展；MOVK 只替换部分位，需找到其余位的有效定义。任何未恢复的部分都不能默认是零。
- 调用按已确认 ABI 切断 caller-saved 寄存器的旧来源；返回值须重新建链。最小实现可直接在调用处停止。遇到跳转、路径合流或返回，只有控制流和来源均已确认才继续；不能将线性相邻指令当作必经路径。
- 无法判断一条指令是否改写相关寄存器或改变路径时终止该候选。可用已观察指令白名单，不凭宽泛指令类别推断“没有覆盖”。

例如下面的示意序列不能把 `down_read` 的 x0 追溯到第一条 ADD，即使此前已经确认 x19 是目标对象：

```asm
add x0, x19, #0x100
bl  helper           // x0 属于 caller-saved，旧字段地址来源在此失效
bl  down_read
```

## 有界归一化跳板入口

先确认目标实际存在的跳板形式，再解析该形式。例如允许的 BTI/HINT 后接直接 B：只跳过已确认可跳过的具体编码，计算分支目标并继续解码；不把 BL 当作普通跳板，也不统一跳过所有 HINT/PAC。

每跳核对指令可读、地址对齐、目标落在已确认代码区域，并设置有限跳数和环检测。越界、读失败、循环或未支持形态均返回具体失败。长跳转 veneer 只有寄存器构造和最终目标均能确认时才支持。

保留“原始符号／入口 → 跳转链 → 实际函数体”的关系。供扫描去重的函数体地址不自动替换 hook 地址或回调指针；这些地址的 CFI、ABI 和身份用途分别核对。

## 候选按来源去重，冲突按语义处理

分析记录至少能还原：目标镜像／构建、字段、原始锚点、实际函数体、窗口和使用点指令位置、基址与用途的数据流、候选值及拒绝原因。按需保存在离线记录或 debug 诊断中，不为记录另加无用途的运行时框架。

同一实际函数体的符号别名、同一使用点的重复命中不算独立证据。同一函数内不同位置也先确认是否为同一语义操作的展开或重复；函数名数量和命中次数不能代替来源独立性。单个语义充分的锚点不因缺少“第二票”而自动失效。

需要交叉验证时，选择有独立用途依据的锚点。结果不一致先定位字段含义、参数来源、别名或控制流差异；必要字段仍有未解释冲突就失败。计数可用于诊断和排查排序，不用于覆盖冲突或接受尚未证明的布局。

## nofault 约束访问，不证明布局

读取不确定地址且需要容错时，优先使用目标支持、签名及返回语义已核对的 nofault 接口，检查请求范围是否完整读取，失败立即放弃本次候选；部分结果不能继续解释为完整指令或对象。没有合适接口时停止该探测路径，不改成直接解引用试错。已有证据充分的有界代码读取按原契约维护，不因引入此方法统一增加 nofault 依赖。

nofault 成功只表明该次读取完成，不证明地址属于预期类型、偏移正确、对象仍存活或多次读取来自一致快照。锁、引用、RCU 及页表／数据页生命周期仍按原生契约处理。缺少必要锁偏移或保护机制时停止加载；只读访问也不能据此改为 lockless。可选功能的降级须保持其仍执行路径的同步与生命周期保证。

## 按识别器选择反例

修改实际识别器时，保留既有 Oracle，并追加与改动有关的反例；无需为未支持的指令实现整套矩阵：

- 回溯：BL/BLR 隐式覆盖、LDP 第二目的寄存器、访存基址写回、STXR/CAS、W/X 截断、未知覆盖及分支合流。
- 边界：使用点在窗口首尾、所需定义恰好在下界之外、前瞻越上界；宿主测试可用保护页或有界读接口检查越读。
- 跳板：正常链、循环、越界／未对齐目标、取指失败、未支持的提示或跳转形式。
- 候选：别名／重复使用点不增加独立证据；独立锚点冲突不因某值命中较多而通过。
- 探测读取：读取失败和部分读取均终止候选；读取成功仍需通过原有字段语义检查。

生产动态算法与离线执行保持一致；参考值来自目标 BTF 或独立依据。以上是实现方自检方法，审计和真机结论由各自角色产出。
