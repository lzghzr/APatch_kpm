# NoMount 配套模块更新记录

本文件是配套 ZIP 的更新记录（供 `update.json` 的 `changelog` 指向）。
KPM 自身的能力变化见 [../README.md](../README.md)。

## v2.2.0-20261022

- 控制协议升至 **v22**：与 KPM 必须成组更新并重启，旧协议会被拒绝。
- 安装脚本按设备驱动版本与协议版本校验后再落盘，不匹配时明确中止并给出提示。
- 支持 UID 范围与排除范围、opaque 目录、`.remove` 与带内容的 `.replace` 规则。
- WebUI 与 CLI 的版本显示与 KPM 保持一致（`2.2.0-20261022`）。

## v2.1.1-20261020

- 控制协议 v21；配套脚本适配新的状态查询入口。
- 修正卸载时未清理运行时规则的问题。

## v2.1.1-20261018

- 控制协议 v21；随 KPM 2.1.1 系列发布。
