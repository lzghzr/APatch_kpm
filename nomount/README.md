# NoMount

把普通模块里的系统应用和文件加入系统，系统分区保持原样。

## 安装与查看

1. 选适合自己设备的 NoMount KPM，在 APatch 的内核模块页面点「安装」或「嵌入」，重启。
2. 安装配套 **`NoMount-kpm.zip`（必须）**，重启。

本次要用的 KPM 若已安装或嵌入并成功加载，可直接进行第 2 步。

在 APatch 中确认 NoMount 显示已加载，打开 NoMount 的 WebUI 查看状态和文件规则。

## 日常管理

- 更新：确认新版支持自己的设备，成组更新 KPM 与配套 ZIP 后重启。
- 停用：在 APatch 中停用配套模块，再重启。
- 卸载：卸载配套 ZIP；KPM 先取消嵌入或删除已安装文件，再重启，不要直接卸载正在运行的 KPM。

适用于 Android 64 位设备，内核 4.4～6.1 须先确认设备适配。

来源与许可见 [UPSTREAM.md](UPSTREAM.md)；配套模块更新记录见 [module/CHANGELOG.md](module/CHANGELOG.md)。
