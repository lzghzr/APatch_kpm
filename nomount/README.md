# NoMount

把模块里的系统应用和文件加入系统，文件仍保存在数据分区，系统分区保持原样。

需要同时安装内核模块和配套的 `NoMount-kpm.zip`。配套模块会在开机时加载普通模块中的文件，并提供 WebUI 管理界面。

## 选择版本

| 文件 | 用途 |
| --- | --- |
| `NoMount.kpm` | 动态版，加载时自动获取内核布局 |
| `NoMount_baselines.kpm` | 静态基线，按设备镜像适配后使用 |
| `NoMount-kpm.zip` | 配套元模块，负责开机加载和 WebUI |

实际 KPM 文件名会带版本号，在 APatch 中都叫 `NoMount`，两种版本选一个。原始 `_baselines.kpm` 是移植模板，不能直接加载。

面向 Android ARM64，当前适配范围为 4.4～6.1。已在 4.4、4.19 和 5.15 设备验证；6.1 只有离线适配，其他设备需要另行确认。

没有 BTF 的设备可能需要按镜像适配静态版。同一内核版本的其他设备也需要单独确认。

## 安装

1. 在 APatch 中嵌入适合设备的 NoMount KPM，参数留空，加载时机用默认设置，然后重启。
2. 在支持元模块的 APatch 中安装 `NoMount-kpm.zip`。
3. 安装需要的普通 ZIP 模块，再重启，让其中的系统应用和文件生效。

安装提示“无法连接 NoMount”时，先确认 KPM 已嵌入，并且已经重启。

WebUI 可以查看加载状态、管理文件规则，以及选择不使用注入文件的应用。配套模块的更新和停用方法见 [使用说明](module/README.md)。

**请勿直接卸载已加载的 KPM。移除时先取消嵌入，再重启设备。**
