1. 在 5.15 设备上用对应目标的静态派生件做引导嵌入（`post-kernel-init`，参数留空），CFI 前置按 DEV-034 §9 修订判据；

4. 如设备可用，回归 4.19（`boot_los23.2-v3` / `boot_67.2.A.3.178`）与 4.4（`B2N-416G-v3`，用旧 KP `legacy-kp` 段）；

6. **禁止卸载与动态重载**（RA-002）；死机/卡死立即停止并升级。
