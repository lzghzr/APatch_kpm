- **源码与 Makefile 只面向当前 KP SDK**：`zram_zstd/Makefile` 无任何低版本兼容目标或分支；
  仅有静态布局使用的公共工具 `patch_offsets.py baseline`（非兼容手段）；
- **旧 KP 兼容只在构建后的 KPM 字节上做**：两份派生件由 `patch_offsets.py legacy-kp` 在普通候选构建完成后独立运行生成；
- **派生件不登记为编译变体**（开发者与维护者一致）：登记在模块记录的 `binary_ports[]`，含基准实例、基准哈希、
