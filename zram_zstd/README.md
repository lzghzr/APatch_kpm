# zram_zstd

为手机的内存压缩（zram）增加 ZSTD 1.5.7 与 LZ4 1.10.0。

## 选哪个文件

- `zram_zstd.kpm`：普通版，通常选这个；实际文件名可能带版本号。
- `zram_zstd_baselines.kpm`：须由 AI 为设备准备后使用，原始模板不能直接安装。

只选一个版本。

## 安装与查看

1. 在 APatch 的内核模块页面选择「安装」，然后重启。
2. 还需让设备的 zram 配置使用 `zstd-kpm` 或 `lz4-kpm`，并设为开机生效。

## 更新与停用

- 更新：确认新版适配设备，替换已安装文件后重启，并重新查看算法和交换空间状态。
- 停用或移除：先把开机配置切回设备可用的原算法，再取消嵌入或删除已安装文件并重启；不要直接卸载正在运行的模块，否则可能崩溃。

适用于 Android 64 位设备，内核 4.4～6.6 须先确认设备适配。

## 更新记录

### 1.1.0

新增 `lz4-kpm`：LZ4 1.10.0 默认压缩，不含 HC<br />
算法版本见加载日志、模块元信息与本页

### 1.0.0

未选用时也在 zram 压缩算法列表中显示 `zstd-kpm`<br />
支持 zram 内建及 `zram.ko` 稍后加载，已有算法列表与选中状态保持<br />
列表显示无法接入时，仍可直接指定 `zstd-kpm`

### 0.4.0

算法名改为 `zstd-kpm`，可与内核自带 ZSTD 并存、分别选择<br />
适配仓库中的 4.19、5.4、5.10、5.15、6.1、6.6 内核布局<br />
共同结构定义集中到 `zs_structs.h`，其余字段通过 BTF 或短函数取得

### 0.3.0

ZSTD 升级到 1.5.7 内核分支，源码固定在子模块提交中<br />
改用新的静态工作区接口<br />
完成 4.4、4.9、4.14 的宿主机自检

### 0.2.0

增加 4.9、4.14 内核适配和旧 KP 支持<br />
通过 Git 子模块固定 ZSTD 源码版本<br />
控制接口沿用 rek 的彩蛋

### 0.1.0

加入 ZSTD 压缩和解压<br />
加载时检测内核是否已经支持 ZSTD<br />
提供动态版和静态基线两种构建方式
