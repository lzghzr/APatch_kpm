# zram_zstd

## 模块作用

为手机的内存压缩（zram / 交换空间）增加 ZSTD、LZ4 与 LZ4KD 压缩算法支持，提升内存压缩效率与多任务流畅度。

## 选哪个文件

发布件一般包含两种类型（实际文件名可能带有版本号）：

- `zram_zstd.kpm`：普通版，**绝大多数用户选择此文件**。开机由模块自动适配设备。
- `zram_zstd_baselines.kpm`：静态基线件，属于模板文件。需要根据具体设备的内核布局替换相关参数后才能使用，直接安装不会生效。

通常只需下载并安装普通版（单个文件）即可。

## 安装

1. 打开 APatch 管理器，进入「内核模块」页面。
2. 选择「安装」，选取下载好的 `.kpm` 文件。
3. 安装完成后重启手机。

## 使用

安装并重启后，模块已将新算法注册到系统中。若要实际生效，还需让系统的 zram 配置选用新算法：

1. 可以通过日常使用的内核/性能调节工具，或在系统的开机脚本中，将 zram 压缩算法设置为以下名称之一：
   - `zstd-kpm`：压缩率最高，解压相对较慢，适合内存紧张、能接受较长解压时间的场景；
   - `lz4-kpm`：压缩率较低、解压较快，适合在意响应速度的场景；
   - `lz4kd-kpm`：压缩率与 `lz4-kpm` 相近、解压更快（仅 4 KiB 内存页设备可用）。
2. 将该配置保存并设为开机生效。
3. 可通过查看 `/sys/block/zram0/comp_algorithm` 确认当前正在生效的算法（被中括号 `[...]` 包裹的项即为当前使用的算法）。

## 更新与停用

- **更新模块**：直接下载新版 `.kpm` 文件，在 APatch 中替换安装并重启手机。
- **停用或卸载**：
  1. **切勿在系统运行中直接卸载正在工作的模块**，否则可能导致系统崩溃或死机。
  2. 停用前，请务必先将系统的 zram 压缩算法切换回设备自带的原算法（如 `lzo` 或 `lz4`）。
  3. 确认 zram 已切回原算法后，再在 APatch 中取消嵌入或删除模块，并重启手机。

## 兼容性

- **设备架构**：适用于 Android ARM64 设备。
- **内存页大小限制**：`lz4kd-kpm` 需要 4 KiB 页内核。如果设备使用的是 16 KiB 或 64 KiB 等其它页大小，模块会自动跳过该算法（算法列表中不会出现 `lz4kd-kpm`），这属于正常现象，其它算法不受影响。
- **较新内核支持**：部分较新内核的直连支持仍在验证中，设备能否使用取决于其内核实际具备的能力，而非按 Android 版本号判断。
