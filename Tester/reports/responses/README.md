# Tester 修复响应

维护者流程记录：本目录约定由维护者建立；修复响应由 Tester 本人追加。

- 命名：`<日期>-<问题编号>-<轮次>.md`；每份响应对应一个问题，重复修复使用新轮次。
- 模板：[Tester 修复响应](../../../docs/templates/tester-response.md)。
- 工具修复绑定完整工具 commit、冻结状态与逐文件 SHA-256；使用产物时附完整 source_commit、instance_id 与产物 SHA-256。
- 未冻结修复用参考 HEAD 和工作树字节哈希留痕，关闭仍按问题单的冻结与独立复核条件执行。
- mock、离线与真机证据分别记明，列出 PASS/FAIL/SKIP 与未覆盖原因；敏感原始证据保存在忽略的本地证据目录，正式响应只放脱敏摘要、相对路径和哈希。
- Tester 声明修复进展；维护者同步状态。独立于 owner 的复核者确认关闭，临时措施保留至关闭条件达成。
- 响应只追加；原始证据与既有结论保留。
