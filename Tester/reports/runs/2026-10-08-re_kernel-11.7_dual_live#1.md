# 实机报告：re_kernel 11.7 异步清理过滤规则更新双机型实机加载与推导验证

角色：Tester（真机测试）。  
运行编号：`2026-10-08-re_kernel-11.7_dual_live#1`。  
测试说明：本轮针对 `re_kernel` 升级至 `11.7`（对齐基础异步清理规则，增加锁内二次状态校验，严格限定 TF_ONE_WAY 纯数据消息，排除含对象/FD，未投递事务安全释放；推导增加 binder_dead 短锚点）的冻结候选（提交 `2074106`），在两部实体测试机上执行实机验证。覆盖 Debug 与 Release 双变体在 Linux 5.15 与 Linux 4.4 上的动态推导、热加载、版本核验、ctl0 响应、异步清理规则生效及安全卸载。
