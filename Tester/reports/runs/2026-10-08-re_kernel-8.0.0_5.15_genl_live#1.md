# 实机报告：re_kernel 8.0.0 Genl 修复版在 Linux 5.15 内核动态推导与实机热加载验证

角色：Tester（真机测试）。  
运行编号：`2026-10-08-re_kernel-8.0.0_5.15_genl_live#1`。  
测试说明：本轮针对开发者对 Sony 5.15 内核 Generic Netlink 汇编特征修复后的 `re_kernel` 8.0.0 冻结候选（commit `f80c9a2` / `a7cf963`，扩展扫描窗口至 25 条并支持头部配置识别），在物理真机 Sony Xperia 1 V（Linux 5.15.189，设备指纹 `48b7ee2f`）上执行实机验证。覆盖 Debug 与 Release 双变体的热加载、动态反汇编推导日志、ctl0 控制接口、Generic Netlink 注册、FIFO 异步消息淘汰及干净卸载。
