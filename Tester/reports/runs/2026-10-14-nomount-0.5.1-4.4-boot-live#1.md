# 实机报告：nomount 0.5.1 4.4 Nokia 7 plus 派生件实测（安全上下文修复、用户主路径覆盖、单变体回归）

角色：Tester（真机测试）。  
运行编号：`2026-10-14-nomount-0.5.1-4.4-boot-live#1`。  
测试依据：响应维护者轮次请求 [`docs/records/2026-10-14-nomount-0.5.1-round-request.md`](../../../docs/records/2026-10-14-nomount-0.5.1-round-request.md)、缺陷单 `DEV-036` 回归要求与风险接受记录 `RA-002`，针对 `B2N-416G_boot.img` 目标核对 0.5.1 在册派生哈希、基准实例与配套 ZIP 身份。依据 Auditor 独立审计报告（`Auditor/reports/2026-10-14-nomount-0.5.1-module-audit.md` §2）关于 release 与 debug 变体差异仅限于版本字符串字面量的判定及维护者单变体测试判据（[Tester 手册 §4.1](../../../docs/process/tester-handbook.md)），在 Linux 4.4 真机（Nokia 7 plus）上对 release 变体完成引导嵌入、极早期自动加载（`pre-kernel-init`）、配套 ZIP 模块安装与卸载全流程验证。落实 [Tester 手册 §4.2](../../../docs/process/tester-handbook.md) 用户主要操作覆盖要求：在 SELinux `Enforcing` 模式下注入真实应用并完成 ART 编译、普通应用域（`u:r:untrusted_app:s0`）加载执行与内存映射，并完成全量常规回归判据（重定向、Whiteout、目录合并、非 root mmap 与 `/proc/self/maps` 防泄漏、阴性对照、UID 隔离屏蔽与恢复）。
