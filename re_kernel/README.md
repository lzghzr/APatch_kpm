# ReKernel

基于 [Re:Kernel](https://github.com/Sakion-Team/Re-Kernel/tree/main/LKM-Source)，向配套墓碑应用报告应用活动，帮助它判断何时解冻，并清理重复消息；需要支持 Re:Kernel 的墓碑应用。

## 选哪个文件

- `re_kernel.kpm`：普通版；实际文件名可能带版本号。
- `re_kernel_baselines.kpm`：须由 AI 为设备准备后使用，原始模板不能直接安装。

只选一个版本。

## 安装与查看

1. 在 APatch 的内核模块页面为适配设备的文件选择「安装」，然后重启。
2. 打开配套墓碑应用并连接模块，按应用说明完成设置。

## 更新与停用

- 更新：确认新版适配自己的设备，替换已安装文件后重启。
- 停用或移除：先取消嵌入或删除已安装文件，再重启。

适用于 Android 64 位设备，内核 4.4～6.6 须先确认设备适配。
