# ReKernel

## 模块作用

基于 [Re:Kernel](https://github.com/Sakion-Team/Re-Kernel/tree/main/LKM-Source) 的 KernelPatch 模块（KPM）移植版本。

作为 Android 墓碑机制的内核侧协作组件，与上层支持 Re:Kernel 协议的墓碑模块配合使用。

> 注意：本模块与 `re_kernel_x` 属于同类组件，功能重叠，**同一台设备只需安装其中一个即可**，请勿同时安装两者。`re_kernel` 覆盖面更宽，兼容性经过了长期验证。

## 选哪个文件

发布件一般包含两种类型：

- `re_kernel.kpm`：普通版（动态版），**绝大多数用户选择此文件**。开机加载时优先通过内核 BTF 获取结构体偏移，若无 BTF 则通过内核函数自动推导。
- `re_kernel_baselines.kpm`：静态基线件，属于模板文件。需要根据具体设备的内核镜像提取并填入偏移参数后才能使用，直接安装不会生效。

通常只需下载并安装普通版即可。

## 安装

1. 打开 APatch 管理器，进入「内核模块」页面。
2. 先「加载」测试，不报错不死机，再选择「安装」（推荐方式），选取下载好的 `re_kernel.kpm` 文件。
3. 安装完成后重启手机。
4. 重启后在 APatch 中确认模块已加载；打开支持 Re:Kernel 协议的配套墓碑模块，连接模块并按应用说明完成配置。

## 使用

1. 安装并重启后，模块会在内核后台运行并建立 `rekernel` 通信接口。
2. 打开配套墓碑模块，配置需要冻结的黑白名单、网络解冻等。

## 更新与停用

- **更新模块**：直接下载新版 `re_kernel.kpm` 文件，在 APatch 中替换安装并重启手机。
- **停用或卸载**：在 APatch 中删除已安装的 `re_kernel` 模块，然后重启手机。

## 兼容性

- **设备架构**：适用于 Android ARM64（64 位）设备。
- **内核范围**：支持 Linux 内核 4.4 ～ 6.12。
- **机型定制差异**：各机型厂商定制内核的 Binder 驱动结构存在差异，若动态版在特定机型上推导失败，可通过静态基线方式为该机型进行离线适配。
